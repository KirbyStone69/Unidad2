# Visualizador de grafos

- `los4/`: versión de los cuatro algoritmos y sus informes.
- `Version_previa/`: módulos de interfaz y búsqueda conservados de la carpeta anidada original.
- `Ejercicios_previos/`: dibujos de grafos y recursos HTML.

Se conservan versiones separadas. `los4/main.py` busca un paquete `interfaz` que no está en esa versión; `Version_previa/main.py` también lo busca, aunque sus módulos están bajo `ADB_Interfaz`. Esta organización no repara ni mezcla automáticamente esas versiones.
