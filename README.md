## Estado de las prácticas

Se conserva el código existente; la organización no implica que todas las aplicaciones estén completas. Los puntos de entrada de grafos buscan un paquete `interfaz` que falta en los archivos disponibles; además, el punto de entrada de `inteligenciaArtesanal` requiere `modelos`. La función `dfs` de `datos.py` solo examina vecinos inmediatos, sin implementar todavía un recorrido completo.

Los entornos Python, `node_modules`, las configuraciones privadas y los archivos temporales no se publican. Instala las dependencias de cada proyecto antes de ejecutarlo.
