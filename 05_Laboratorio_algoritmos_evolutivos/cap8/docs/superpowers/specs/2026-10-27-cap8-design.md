# Hyperparameter Lab: diseño

Solicitud: CLI educativa completa en Python 3.13 basada en el PDF local (capítulo 8,
páginas impresas 207–222), con Wine, AdaBoost, tres métodos, menú Rich, exportación y pruebas.
La estética anterior se adapta a terminal: fondo verde bosque, acentos neón,
texto claro, advertencias ámbar; las curvas ganadoras se destacan en rojo oscuro.

Decisiones de implementación: módulos separados para espacios, evaluación,
búsqueda, persistencia, gráficas e interfaz. DEAP se usa directamente en ambos
AG; no se usa sklearn-deap antiguo. Grid exhaustivo y genético comparten exactamente
la misma cuadrícula. Directo usa dos genes reales; n_estimators se redondea y
learning_rate se conserva. SAMME es fijo: scikit-learn instalado 1.9.1 ya no tiene
argumento algorithm. No se inventa otro hiperparámetro para sustituir SAMME.R.

Alternativas: replicar dependencias antiguas impediría la compatibilidad pedida;
GridSearchCV sin bucle explícito dificultaría comunicar cada evaluación. Se elige
ParameterGrid + cross_val_score y DEAP con ciclo generacional explícito elitista.

Por defecto: cuadrícula 10..100 paso10 y logspace(-2,0,10): 100 combinaciones
actualmente compatibles; población20, generaciones5, cruce0.8, mutación0.3,
élite1, torneo2, eta20. Validación StratifiedKFold(5, shuffle=True, random_state=42).
Cada método tiene caché independiente; se distinguen solicitudes de fitness de
configuraciones realmente entrenadas. Se registran scores por fold, tiempos,
versiones, semilla, particiones identificadas por hash y presupuesto completo.
Baseline AdaBoost por defecto se evalúa aparte y se cronometra separadamente.
Los resultados CV usados para seleccionar son resultados observados; no prueba
independiente ni garantía de óptimo global. Comparación con mismos folds no supone
igual presupuesto. No hay GUI PyQt ni web, conforme a la nueva solicitud de CLI.

Persistencia: JSON completo versionado; CSV resumen, evaluaciones e historial;
PNG opcional con accuracy máxima/media por generación y comparación accuracy/tiempo.
Ctrl-C termina sin traceback y sin presentar resultados incompletos como completos.
Entradas JSON y CLI se validan antes de entrenar. Menú con ocho opciones y
subcomandos por --method, además --grid, --bounds, --folds, --elite y --plots.
