# Hyperparameter Lab Implementation Plan

**Goal:** CLI funcional y verificable de las tres estrategias del capítulo 8.
**Architecture:** Espacios → evaluador CV reproducible → motores → resultados → Rich/exportación.
**Tech Stack:** Python3.13, NumPy, Pandas, sklearn1.9.1, DEAP, Rich, Matplotlib, pytest.
**Spec:** docs/superpowers/specs/2026-10-27-cap8-design.md

## Restricciones y revisión
- No SAMME.R, algorithm ni sklearn-deap incompatibles.
- Sin particiones distintas entre métodos ni caché compartida en comparación.
- Validar NaN, probabilidades, intervalos, grids vacíos, elitismo y folds antes de entrenar.
- Individuos repetidos reutilizan fitness; contadores distinguen solicitudes y entrenamientos.
- Archivos cargados se validan; no ejecutar código desde JSON.
